---
title: Error Codes
---

Defined in `com.chainup.custody.result.MerchantOpenApiResultCode` (1xxx～4xxx), isolated from internal `ApiResultCode` (6 digits).

<Note>
- HTTP status code is generally **200**. Judge business success/failure through response body `code`; `code = 0` means success, non-zero means failure.
- **Multi-language**: `msg` prioritizes `config_language` corresponding `languageKey`; request header `Language` controls Chinese/English (e.g., `zh_CN` / `en_US`).
- **Field placeholder**: Text containing `%s` is injected with field names by `MerchantResultUtil`; multiple fields concatenated with `, ` (e.g., `card_bin_no, package_no Invalid request parameter`).
- Parameter error codes **1004, 2007～2010, 4010**, etc. include **snake_case field name** before/after description.
</Note>

## Error Code Ranges

| code | Description (English) | Description (Chinese) |
| ---- | -------- | -------- |
| 0 | Success | 成功 |
| 1xxx | Common, auth, and PCI errors | 公共异常、权限异常、鉴权异常、PCI 相关 |

| 3xxx | Account and transfer errors | 账户、划转相关异常 |
| 4xxx | Card, transaction, and privacy errors | 卡、卡交易、卡隐私相关异常 |
