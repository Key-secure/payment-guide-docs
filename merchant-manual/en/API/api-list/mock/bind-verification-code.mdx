---
title: Simulate Bind Verification Code
api: POST /open-api/v1/simulate/bind_verification_code
authMethod: none
hidden: true
---

Simulates a **card bind / app verification code** callback.

<Note>
- These APIs **do not use** `Api-Key` / `Access-Token` authentication
</Note>

## Request Headers

<ParamField header="Content-Type" type="string" required default="application/json">
  Fixed to `application/json; charset=utf-8`
</ParamField>

## Request Body

<ParamField body="card_no" type="string" required>
  Card number
</ParamField>

<ParamField body="opt_type" type="string" required>
  Operation type (e.g. `BIND`)
</ParamField>

<ParamField body="otp" type="string" required>
  Verification code
</ParamField>

## Response

<ResponseField name="code" type="number">
  Status code. `0` means success. On failure it matches the HTTP status (e.g. `400` / `500`)
</ResponseField>

<ResponseField name="msg" type="string">
  Response message. `Success` on success, or a specific error reason. No `data` field
</ResponseField>

<RequestExample>

```bash Request
curl --request POST \
  --url https://sandbox-openplatform.keysecure.io/open-api/v1/simulate/bind_verification_code \
  --header 'Content-Type: application/json' \
  --data '{
    "card_no": "6220012345678901",
    "opt_type": "BIND",
    "otp": "123456"
  }'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "code": 0,
  "msg": "Success"
}
```

</ResponseExample>
