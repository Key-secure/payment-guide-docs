title: Simulate Token Verification (ByCard)
api: POST /open-api/v1/simulate/external_api/simulate_tevau_token
authMethod: none
hidden: true
---

Forwards a ByCard sandbox token verification notification. `card_no` is looked up and converted to `out_card_no` before calling the sandbox. `case_type` is mapped to upstream `app_type`.

<Note>
- Path suffix: `/external_api/simulate_tevau_token`
- These APIs **do not use** `Api-Key` / `Access-Token` authentication
</Note>

## Request Headers

<ParamField header="Content-Type" type="string" required default="application/json">
  Fixed to `application/json; charset=utf-8`
</ParamField>

## Request Body

<ParamField body="card_no" type="string" required>
  Card number (converted internally to `out_card_no`)
</ParamField>

<ParamField body="case_type" type="string">
  Scenario type (mapped to upstream `app_type`, e.g. `BIND`)
</ParamField>

## Response

<ResponseField name="code" type="number">
  Status code. `0` means success. On failure it matches the HTTP status (e.g. `400` / `500`)
</ResponseField>

<ResponseField name="msg" type="string">
  Response message. `Success` on success, or a specific error reason. No `data` field
</ResponseField>

<RequestExample>

```bash Request
curl --request POST \
  --url https://sandbox-openplatform.keysecure.io/open-api/v1/simulate/external_api/simulate_tevau_token \
  --header 'Content-Type: application/json' \
  --data '{
    "card_no": "6220012345678901",
    "case_type": "BIND"
  }'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "code": 0,
  "msg": "Success"
}
```

</ResponseExample>
