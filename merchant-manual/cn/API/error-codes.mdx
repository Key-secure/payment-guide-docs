---
title: 错误码
---

定义于 `com.chainup.custody.result.MerchantOpenApiResultCode`（1xxx～4xxx），与内部 `ApiResultCode`（6 位）隔离。

<Note>
- HTTP 状态码一般为 **200**，通过响应体 `code` 判断业务成败；`code = 0` 表示成功，非 0 为失败。
- **多语言**：`msg` 优先取 `config_language` 中对应 `languageKey`；请求头 `Language` 控制中英文（如 `zh_CN` / `en_US`）。
- **字段占位**：含 `%s` 的文案由 `MerchantResultUtil` 注入字段名；多字段时以 `, ` 拼接（如 `card_bin_no, package_no 请求参数不合法`）。
- 参数类错误 **1004、2007～2010、4010** 等会在描述前/后附带 **snake_case 字段名**。
</Note>

## 错误码分段

| code | 中文描述 | 英文描述 |
| ---- | -------- | -------- |
| 0 | 成功 | Success |
| 1xxx | 公共异常、权限异常、鉴权异常、PCI 相关 | Common, auth, and PCI errors |
| 2xxx | 会员/持卡人相关异常 | Cardholder errors |
| 3xxx | 账户、划转相关异常 | Account and transfer errors |
| 4xxx | 卡、卡交易、卡隐私相关异常 | Card, transaction, and privacy errors |
