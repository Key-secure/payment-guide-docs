---
title: 通知说明
description: 了解通知失败后的自动重试与手动重发机制
---

平台通过商户配置的通知地址发送业务通知。商户接收通知后，应按照各通知文档约定的格式返回成功应答。

## 自动重试

对于支持重试的异步通知，如果出现请求超时、连接失败，或平台未收到成功应答（`code = 0`），平台会按照通知重试策略自动重试。

<Note>
由于自动重试可能导致同一通知被多次发送，商户应根据通知 ID 或业务单号进行幂等处理，避免重复处理业务。
</Note>

授权模式下的 Auth 订单通知用于实时授权确认，需要商户在规定时间内完成应答。超时或应答失败时，平台会按照授权编排策略处理，不适用普通异步通知的重试机制。

## 手动重发

如果通知自动重试后仍未成功，商户可以在商户后台找到对应的业务记录，并手动发起通知。

在商户后台，找到通知失败的记录，然后点击右侧操作栏中的重试按钮。

![手动重发通知参考图](/cn/images/api-notification-manual-retry.png)

手动发起的通知也可能与之前发送的通知重复，商户仍需进行幂等处理。处理完成后，可结合商户后台记录和自身系统日志确认通知结果。

<Warning>
请确保通知地址可以通过公网访问，并及时返回应答。不要在通知请求中执行耗时较长的同步业务，以免因响应超时触发重复通知。
</Warning>
