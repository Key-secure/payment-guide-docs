---
title: 获取卡隐私信息（JSON 加密）
api: GET /open-api/v1/card/{card_no}/private/info
authMethod: none
---

获取卡隐私 JSON 加密信息（需开通 PCI，`pci_flag=1`）。

## 请求头

<ParamField header="Api-Key" type="string" required placeholder="your_api_key">
  apiKey（商户凭证，与 IP 白名单绑定）
</ParamField>

<ParamField header="Timestamp" type="string" required default="1716307200000">
  Unix 时间戳（毫秒），与服务端偏差须在 60 秒内，且不接受未来时间戳
</ParamField>

<ParamField header="Access-Token" type="string" required placeholder="your_access_token">
  登录标识（除获取 Token 外必填）
</ParamField>

<ParamField header="accept" type="string" default="application/json">
  固定为 `application/json`
</ParamField>

## 路径参数

<ParamField path="card_no" type="string" required default="C202605220001">
  卡单号
</ParamField>

## 返回参数

<ResponseField name="code" type="number">
  响应状态码，`0` 表示成功
</ResponseField>

<ResponseField name="msg" type="string">
  响应消息
</ResponseField>

<ResponseField name="data" type="string">
  MerchantEncryptUtil 加密后的 JSON 字符串（AES/CBC），解密后含 pan、cvv、exp_year、exp_month 等
</ResponseField>

<RequestExample>

```bash Request
curl --request GET \
  --url https://sandbox-openplatform.keysecure.io/open-api/v1/card/C202605220001/private/info \
  --header 'accept: application/json' \
  --header 'Api-Key: your_api_key' \
  --header 'Timestamp: 1716307200000' \
  --header 'Access-Token: your_access_token'
```

</RequestExample>

<ResponseExample>

```json Response
{
  "code": 0,
  "msg": "Success",
  "data": "Base64EncodedEncryptedString..."
}
```

</ResponseExample>
