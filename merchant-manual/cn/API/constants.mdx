title: 常量表

以下枚举定义于 `com.chainup.custody.enums.api` 包。开放 API 对外展示值与枚举 **name** 一致（JSON 字段为 snake_case 时由框架序列化，枚举名本身见下表 **code** 列）。

## 8.1 通用状态（ApiCommonStatusEnum）

用于划转流水、消费记录等通用业务状态。

| code | 描述 | 内部状态码 |
| ---- | ---- | ---------- |
| Pending | 进行中 | 1000 |
| Success | 成功 | 2000 |
| Fail | 失败 | 3000 |

## 8.2 卡状态（ApiCardStatusEnum）

用于卡列表、卡详情、修改卡状态等接口的 `status` 字段。

| code | 描述 | 说明 |
| ---- | ---- | ---- |
| Pending | 进行中 | 开卡/制卡中等 |
| ToActivate | 待激活 | 待持卡人激活 |
| Activated | 已激活/正常 | 修改状态接口可传此值表示启用 |
| Fail | 失败 | 开卡失败等 |
| Frozen | 已冻结 | 修改状态接口可传此值表示冻结 |
| Delete | 已删除/注销 | 修改状态接口可传此值表示注销 |

<Note>
修改卡状态接口仅允许传入：`Activated`、`Frozen`、`Delete`。
</Note>

## 8.9 划转类型（ApiTransferTypeEnum）

## 8.11 管理费免除方式（ApiManageFeeFreeTypeEnum）
